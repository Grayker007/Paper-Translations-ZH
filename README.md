# 达哥的论文 / 报告中文翻译

## 命名规则

- 文件夹：`YYMMDD_来源_标题`，和 NAS `Projects-Archive/03_论文翻译/` 保持一致。
- 文件：`标题-纯中文.pdf` / `标题-中英对照.pdf`，有修订版加 `_v2` 等后缀。
- 新文章加到上面目录表的最上面。
